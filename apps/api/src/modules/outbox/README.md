# Outbox module

Persists versioned domain events in the same MongoDB transaction as the business state change. Workers claim events with expiring leases, publish idempotently, then mark them published; retries use bounded exponential backoff and dead-letter exhausted work. Transport delivery is at least once. The publisher reports queue counts, expired leases, pending/dead-letter age and interval publish/retry totals as structured heartbeats. An MFA-protected platform-admin route lists dead-letter metadata and can requeue a reviewed event with an audit reason. Do not enqueue a business event outside the originating transaction.
